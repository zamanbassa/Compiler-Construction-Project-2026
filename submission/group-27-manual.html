Purpose

This program compiles an SPL source file through lexical, syntax, declaration, and type analysis. It writes the accepted syntax tree as XML and, when the third output path is provided, generates a complete human-readable C++ translation unit.

Requirements

Run the submitted executable JAR with Java 21 or newer. The generated C++ file is human-readable and can be inspected or compiled separately. g++ is recommended. If using gcc, explicitly link the C++ standard library as shown below.

Usage

  1. Place group-27.jar and an SPL input file in accessible locations.
  2. Open a terminal in the folder containing the JAR, or use its full path.
  3. Run the compiler with the input, XML output, and C++ output paths:
java -jar group-27.jar path/to/program.spl path/to/tree.xml path/to/program.cpp

The first argument is the SPL input file, the second is the generated XML syntax tree, and the third is the generated C++ source. Parent folders for output files are created when needed. Absolute paths may also be used. The third argument is required to request target-code generation.

Output and Errors

Successful execution reports the completed analysis phases and output paths. A lexical, syntax, semantic, type-analysis, or code-generation error is printed to the error stream and the program exits with a non-zero status.

The SPL lexer requires a blank separator after each token. Spaces, carriage returns, and line feeds are accepted as separators. The dollar sign is not part of an input file; it is only the parser end-of-input notation used in the specification.

Variable and Function Names

A variable and a function may share the same SPL name. The compiler distinguishes their uses by the syntax-tree context: a name in a function-call node followed by parameter parentheses resolves to the function, while a name used as an assignment target or value resolves to the variable. Each use is bound to its corresponding symbol, so a program can, for example, assign to #a and call #a ( ) without confusing the two.

Example

For an input file containing : : print "hello" ; followed by a newline, run:

java -jar group-27.jar example.spl example-tree.xml example.cpp

A successful run creates both example-tree.xml and example.cpp. Compile and run the generated C++ with g++:

g++ -std=c++11 example.cpp -o example
./example

Alternatively, gcc can compile and link the C++ output with:

gcc -std=c++11 example.cpp -lstdc++ -o example
./example
