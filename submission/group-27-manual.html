Purpose

This program performs lexical analysis followed by syntax analysis for an SPL source file. On success it writes the generated syntax tree as XML.

Windows Usage

  1. Extract the submitted ZIP without separating group-27.exe from the jre folder.
  2. Place an SPL input file where you can access it.
  3. Open PowerShell in the folder containing group-27.exe.
  4. Run the executable with an input SPL file and an output XML file:
 .\group-27.exe path\to\program.spl path\to\tree.xml

The first argument is the input file. The second argument is the XML output path. Parent folders for the output file are created by the program when needed. Absolute paths may also be used.

Output and Errors

Successful execution prints the source, token list, lexical-analysis result, syntax-analysis result, and the XML output location. A lexical or syntax error is printed to the error stream and the program exits with a non-zero status.

The SPL lexer requires a blank separator after each token. Spaces, carriage returns, and line feeds are accepted as separators. The dollar sign is not part of an input file; it is only the parser end-of-input notation used in the specification.

Example

For an input file containing:

: : print "hello" ;

run:

 .\group-27.exe example.spl example-tree.xml

A successful run creates example-tree.xml.

Input Formatting

Every SPL token must be followed by a space, carriage return, or line feed. Ensure that the final token, including a final semicolon, is followed by a newline or space. For example:

: : print "hello" ;

Requirements

The submitted ZIP includes a bundled Java runtime in the jre folder, so a separate Java installation is not required. Keep the jre folder beside group-27.exe. The executable must have access to the input file and permission to write the requested XML output.
