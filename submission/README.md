# Group 27 Phase 1 Submission

The Windows submission is produced by `build-submission.ps1` on Windows with a JDK that supports `jpackage` and Windows installer packaging.

The script:

1. Compiles the front-end.
2. Runs all dependency-free regression tests.
3. Builds `group-27.exe` with `jpackage`.
4. Packages `group-27.exe` and `group-27.pdf` as `group-27.zip`.

The PDF manual is already included as `group-27.pdf`. The HTML source is retained as `group-27-manual.html` for editing if the group details change.

This macOS workspace cannot produce a Windows `.exe`. A local runnable JAR smoke test was completed successfully; the final executable must be generated by running the PowerShell script on Windows before uploading the ZIP.
